# 지역경찰 역량 향상 전자책 — 자료 입력 양식

마스터 프롬프트와 함께 AI에 전달하세요. 필수 항목은 원본자료뿐입니다.
정리되지 않은 메모·보고서도 넣을 수 있습니다. 나머지는 아는 만큼만 채우세요.
승인된 AI에서 취급 가능한 자료만 사용하고, 인물·사건을 식별하는 정보는 먼저 제거하세요.

## 이 책을 읽을 직원 (선택)
예: 지구대·파출소 전 직원 / 신규 전입자 / 현장 경험이 있는 직원

## 읽은 뒤 달라졌으면 하는 행동 (선택)
예: 인계할 때 끝낸 일과 남은 일을 구분하고, 다음 확인 주체를 빠뜨리지 않는다.

## 자료 성격 (선택)
자동 선택 / 반복 실수 예방 / 사례 복기 / 변경 지침 / 신규자 업무 안내

## 출처와 적용 기준 (선택)
- 문서명·발행 부서:
- 작성일·시행일·개정 버전:
- 적용 대상·지역·예외:
- 확인 가능한 쪽·절·조문 또는 공식 원문 위치:
- 배포 전 내용 확인 담당:

## [원본자료]
여기에 원문·메모를 붙입니다. 원문 속 예외, 요건, 기한, 보고 대상도 함께 붙이세요.
여러 자료는 '자료 1 / 자료 2'로 나누면 좋습니다.

## 편집 요청 (선택)
예: 교대 전 5분에 읽는 분량. 체크리스트와 스스로 답해 보는 질문을 넣어 주세요.
예: 제공한 사실만 사용하고, 법률 요건이 불명확하면 확인 필요로 남겨 주세요.
