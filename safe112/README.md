# SAFE112 — 외국인 유학생 범죄예방 모바일 웹

경찰서·대학교 국제교류센터·유학생 오리엔테이션에서 **QR코드로 바로 배포**할 수 있는 정적 웹페이지입니다.

목적은 일반 생활정보가 아닙니다.

- 범죄 **피해**를 예방하고
- 자신도 모르게 **범죄에 가담**하는 것을 막으며
- 위험할 때 **112**로 빠르게 도움을 요청하게 합니다.

개인정보(회원가입, 위치, 전화번호)는 수집하지 않습니다.

## 1. 실행 방법 (컴퓨터에서 미리 보기)

이 페이지는 `file://`로 파일을 더블클릭하면 내용이 열리지 않을 수 있습니다.  
**작은 웹서버**로 여는 것이 가장 쉽습니다.

### Windows (Python이 있는 경우)

1. 이 폴더(`safe112`)를 연다.
2. 주소창에 `powershell` 입력 후 Enter.
3. 아래를 붙여넣고 Enter.

```powershell
python -m http.server 8080
```

4. 휴대폰·컴퓨터 브라우저에서 연다.

- 이 컴퓨터: http://127.0.0.1:8080
- 같은 Wi-Fi의 휴대폰: `http://(컴퓨터IP):8080`

종료하려면 창에서 `Ctrl + C`.

### Python이 없다면

## 2. 배포 방법 (유학생에게 QR로 나눠주기)

서버 프로그램 설치가 필요 없는 **정적 파일**입니다. 폴더 전체를 올리면 됩니다.

추천:

1. **GitHub Pages** — 이 폴더를 저장소에 올리고 Pages를 켠다.
2. **Netlify Drop** — https://app.netlify.com/drop 에 폴더를 드래그.
3. 기관 **내부 웹서버** / 대학 홈페이지 하위 폴더.

배포 후 주소를 QR로 만들면 오리엔테이션에서 바로 쓸 수 있습니다.

휴대폰 홈 화면 추가(PWA)가 가능하도록 `manifest.json`과 `sw.js`가 들어 있습니다.  
**처음 한 번은 인터넷이 필요**하고, 그다음부터는 주요 화면이 오프라인에서도 열리도록 설계했습니다.

## 4. 범죄 사례 수정 방법

개발자가 아니어도 됩니다. **메모장**으로 JSON 파일을 수정하세요.

1. 바꿀 내용이 **한국어 문장**이면 `i18n/ko.json`을 연다.
2. 같은 위치의 문장을 `en.json`, `zh-CN.json` 등에도 맞춘다.
3. 저장한 뒤 브라우저를 **새로고침**한다.

예시 — 보이스피싱 설명 고치기:

- 파일: `i18n/ko.json`
- 위치: `crimes` → `voice-phishing` → `what`

상황 대화는 `examples` 안의 `lines` / `stop` / `dont` / `do` 입니다.

**출처·업데이트 날짜**는 사용자 화면에 크게 나오지 않고, 관리용으로 `data/crimes.json`에 남겨 두었습니다.

```json
"updatedAt": "2026-09-11",
"sources": ["경찰청", "금융감독원"]
```

날짜를 바꾸면 상세 페이지 아래에 `최근 업데이트`가 바뀝니다.

내용을 고친 뒤에도 예전 글이 보이면 `sw.js` 맨 위의 `CACHE` 값을 바꾸세요. 예: `safe112-v1-20260911` → `safe112-v2-20260920`. 그러면 휴대폰이 새 파일을 다시 받습니다.

> 확인되지 않은 통계·임의 사례를 “실제 사건”처럼 쓰지 마세요.  
> 경찰청·금감원·공식 보도 기준으로만 수정하는 것을 권합니다.

## 5. 번역 수정 방법

| 언어 | 파일 |
|------|------|
| 한국어 | `i18n/ko.json` |
| English | `i18n/en.json` |
| 中文（简体） | `i18n/zh-CN.json` |
| ภาษาไทย | `i18n/th.json` |
| Bahasa Melayu | `i18n/ms.json` |
| Tiếng Việt | `i18n/vi.json` |

규칙:

- **키 이름**(예: `home.title`)은 언어마다 같아야 합니다. 값만 바꿉니다.
- Google 번역 직역보다, 그 나라 학생이 바로 이해하는 짧은 문장을 쓰세요.
- 따옴표 `"` 를 문장 안에 넣을 때는 `\"` 로 쓰거나, 작은따옴표를 쓰세요. JSON이 깨집니다.
- 쉼표(`,`)를 마지막 항목 뒤에 남기면 오류가 납니다.

수정 후 검사:

```powershell
python tools/validate.py
```

`OK`가 나오면 키 구조가 맞습니다.

언어는 휴대폰에 저장됩니다(`localStorage`). 개인을 식별하는 정보는 넣지 않았습니다.

## 6. 새로운 범죄 유형 추가 방법

1. `data/crimes.json`의 `order` 배열에 **영문 id**를 넣습니다.  
   예: `"ticket-scam"`
2. 같은 파일 `crimes` 배열에 항목을 추가합니다.

```json
{
  "id": "ticket-scam",
  "icon": "🎫",
  "priority": 9,
  "category": "fraud",
  "updatedAt": "2026-09-11",
  "tags": ["티켓", "ticket"],
  "sources": ["경찰청"]
}
```

3. **모든** `i18n/*.json`의 `crimes` 아래에 같은 id로 본문을 넣습니다.

필수 항목:

- `title` 제목
- `short` 홈 카드 한 줄
- `what` 어떤 범죄인가요 (2~3문장)
- `warningSigns` 의심 키워드 배열
- `dont` 하지 마세요 배열
- `actions` 이미 피해를 당했다면 배열
- `policeTip` 경찰이 강조하고 싶은 한 줄

선택 항목:

- `examples` 대화형 사례 (`lines`, `stop`, `dont`, `do`)
- `steps` 로맨스스캠처럼 단계 화살표
- `question` / `questionAnswer` 질문형 경고
- `banner` 화면 맨 위 강한 경고
- `legalLine` 간단한 법령 안내 (어려운 조문 복사 금지)

4. `python tools/validate.py` 로 확인합니다.

---

## 7. 새로운 언어 추가 방법

1. `i18n/ko.json`을 복사해 `i18n/ja.json`처럼 저장합니다.
2. 값만 번역합니다. 키는 그대로 둡니다.
3. `js/i18n.js`의 `LANGS` 배열에 한 줄을 추가합니다.

```javascript
{ id: "ja", label: "日本語", native: "日本語" }
```

4. `data/config.json`의 `supportedLangs`에도 `"ja"`를 넣습니다.
5. `sw.js`의 `ASSETS` 목록에 `./i18n/ja.json`을 추가합니다.  
   (오프라인에서도 새 언어가 열리게 하려면 필요합니다.)
6. `python tools/validate.py`의 `LANGS` 목록에도 추가합니다.

## 9. 콘텐츠를 넣을 때

넣을 것: 접근 수법, 의심 신호, 하지 말 것, 이미 당했을 때, 112.

빼야 할 것: 맛집, 관광, 교통, 비자 행정, 취업 정보, 출처 없는 통계, 법령 원문 나열.

법적 수치(예: 전자금융거래법상 통장 양도 시 5년 이하 징역 또는 3천만원 이하 벌금)를 바꿀 때는 **현행 법령을 다시 확인**하세요.
