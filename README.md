# 경찰 전자책 제작기

Markdown 자료를 올리면 **한 권의 책**으로 조판하고, 화면에서 고친 뒤 **전자책 HTML**로 배포할 수 있는 웹 앱입니다.

서버 없이 `index.html`만으로 동작합니다. 작성 내용은 브라우저 `localStorage`에만 남고 외부로 전송되지 않습니다.

배포 HTML은 카드 목록이 아닙니다. 표지·조판을 그대로 가진 채, **휴대폰에서는 한 쪽씩 꽉 차게, PC에서는 두 쪽 펼침**으로 넘깁니다.

## 바로 쓰기

- 제작기: https://dlrmsals1425-dotcom.github.io/police-ebook-maker/
- 서가(배포된 책 목록): https://dlrmsals1425-dotcom.github.io/police-ebook-maker/books/
- 로컬: `index.html`을 더블클릭 (크롬·엣지 권장)

처음 열면 가상 샘플 「112 중요사건 현장조치 가이드」가 보입니다. 실제 사건·개인정보는 들어 있지 않습니다. 작업을 지우고 이 상태로 되돌리려면 **파일 → 초기화**를 누릅니다. JSON 백업이 없으면 복구할 수 없습니다.

## 책의 모양

- 판형: 신국판 **152 × 225mm**. A4 보고서가 아니라 단행본 비율입니다.
- 인쇄·PC 본문은 **명조(바탕) 계열**, 휴대폰 본문은 **고딕 계열**입니다. 휴대폰은 기본 17px로 읽고 글자 크기를 바꿀 수 있습니다. 종이는 미색입니다.
- 매 쪽 아래에는 **쪽번호만** 찍힙니다. 위쪽 작은 글씨는 지금 읽는 **장 제목**입니다.
- 표지에는 제목·부제·발행 부서·날짜·판 번호만 들어갑니다. 「내부 교육자료」같은 문서 분류를 본문에 반복해 찍지 않습니다. 표지 윗줄의 작은 글씨(`category`)는 비워 두어도 됩니다.

## 기본 사용 흐름

1. **마스터 프롬프트**를 받아 다른 AI 대화창에 붙여넣습니다.
2. 프롬프트 맨 아래 `[원본자료]`에 내 자료·사례·보고서를 붙입니다.
3. AI가 준 Markdown을 **Markdown 불러오기**로 엽니다.
4. 변환 후 **검토** 경고가 있으면 해당 쪽으로 가서 긴 문장만 줄입니다.
5. 가운데 쪽을 클릭해 글을 고치고, 왼쪽에서 순서를 바꿉니다.
6. **책장 넘김 미리보기**로 확인한 뒤 배포 형식을 고릅니다.
   - **내보내기 → HTML 저장**: 브라우저에서 책처럼 넘기는 전자책 파일 하나
   - **PDF 저장**: 인쇄·게시용 (신국판 낱장)

마스터 프롬프트는 원본을 **상황 → 판단 → 행동 → 확인·인계 → 자기점검**으로 재구성합니다. 글자 수 기준은 조판 보장이 아니므로 변환 후 화면과 PDF를 확인하세요.

`index.html`의 **책장 넘김 미리보기**는 현재 편집 중인 책을 실제 배포 리더로 엽니다. 편집 중인 쪽부터 시작하며, PC에서도 모바일 폭으로 표시해 입체적인 넘김·본문 검색·글자 크기를 확인할 수 있습니다. **편집으로 돌아가기**를 누르면 기존 편집 쪽으로 돌아오고, 다시 미리보기를 열면 최신 수정 내용이 반영됩니다.

**책장 넘김 미리보기**는 효과를 확인하는 기능이므로 기기의 동작 줄이기 설정과 관계없이 회전 효과를 켜고 한 쪽 보기로 실행합니다. 일반 배포용 HTML은 동작 줄이기 설정을 따릅니다.

마스터 프롬프트 창에서 **원본자료만 붙여넣어도** 시작할 수 있습니다. 대상 직원과 '읽은 뒤 달라졌으면 하는 행동'을 선택적으로 넣으면 입력값이 포함된 프롬프트를 복사·저장합니다. AI에 자동 전송하지 않으며 창을 닫으면 입력값은 지워집니다. 가상 사례는 기본으로 만들지 않고, 모르는 날짜·조치 요건은 확인 필요로 남깁니다.

- 자료 입력 양식: `prompts/지역경찰_역량향상_입력양식.md`
- 짧은 메모 입력 예: `samples/역량향상_인계메모_입력예시.md`
- 변환 결과 10쪽 예: `samples/역량향상_인계메모_완성예시.md`

예시는 학습 설계를 위한 가상 자료이며 공식 인계 규정이 아닙니다. 완성 예시 Markdown을 제작기에 불러오면 현재 디자인으로 확인할 수 있습니다.

## 휴대폰에서 읽기

휴대폰으로 보는 것이 기본입니다. 링크를 열면 바로 책이 펼쳐집니다.

- 화면 하나가 책의 한 쪽입니다.
- 아래쪽 **이전 / 차례·검색 / 다음** 버튼으로 한 손으로 조작합니다. 버튼의 터치 영역은 최소 44px입니다.
- 좌우로 분명하게 밀면 쪽이 넘어갑니다. 본문을 가볍게 누르는 동작으로는 넘어가지 않습니다. 세로 스크롤·두 손가락 확대·문장 선택 중의 동작은 쪽 넘김과 구분합니다.
- **입체적인 책장 넘김**: 한 쪽 보기에서는 손가락을 따라 책장이 왼쪽 책등을 중심으로 회전하며 뒤쪽 페이지와 그림자가 드러납니다. 화면 너비의 약 22%(최소 64px) 이상 밀고 놓으면 넘어가고, 짧게 밀었다 놓으면 원래 쪽으로 돌아옵니다. 이전·다음 버튼에도 같은 효과가 적용됩니다.
- PC에서는 마우스 왼쪽 버튼으로 본문을 좌우로 끌어도 같은 효과가 동작합니다. 짧게 끌면 돌아오고, 책 바깥에서 버튼을 놓아도 드래그가 종료됩니다. 문장을 선택하려면 `Shift`를 누른 채 드래그합니다.
- 넘김 중 반복 입력은 무시하며, 짧게 밀었다 돌아오는 경우 본문의 스크롤 위치를 유지합니다. 화면 회전·차례 열기·글자 크기 변경 시 진행 중인 넘김을 취소합니다. 기기의 **동작 줄이기** 설정이 켜져 있거나 PC 두 쪽 펼침에서는 회전 없이 이동합니다.
- 위쪽에는 책 제목·현재 쪽·글자 크기를 표시합니다. 상하단 막대는 항상 보이며, 노치와 하단 홈 표시줄을 위한 여백을 둡니다.
- 위쪽 **가** 버튼으로 글자 크기를 4단계(작게·보통·크게·아주 크게)로 바꿉니다. 선택은 기기에 기억됩니다.
- **차례·검색**에서 원하는 쪽으로 갑니다. 검색창에 단어를 입력하면 제목과 본문에 해당 단어가 있는 쪽만 나타나고, 주변 문장을 미리 볼 수 있습니다. 검색어를 지우면 전체 차례로 돌아갑니다. 검색은 인터넷 없이 기기 안에서 처리됩니다.
- 차례·검색은 휴대폰 화면 너비 전체를 사용합니다. 열 때 키보드가 자동으로 뜨지 않으며, 검색창을 눌러 입력합니다. 위쪽의 **닫기 / 처음**은 목록을 내려도 보입니다. **처음**은 첫 쪽으로 돌아갑니다. 키보드 사용 시 `Esc`로 닫고, `Tab`으로 검색창과 검색 결과를 이동할 수 있습니다.
- 읽던 쪽은 기기에 저장되어, 다시 열면 그 자리에서 이어집니다. 아래 가는 금색 줄이 읽은 만큼 찹니다.
- 쪽 내용이 화면보다 길면 그 쪽 안에서 위아래로 스크롤됩니다.
- 화면 회전이나 창 크기 변경 시 현재 쪽의 스크롤 위치를 유지합니다. 검색창이 열려 있다면 그대로 유지됩니다.
- 가로로 돌린 휴대폰도 화면 폭 1000px 이하의 터치 기기에서는 한 쪽을 화면 너비에 맞춰 보여줍니다.

PC에서는 폭이 1000px을 넘으면 자동으로 두 쪽 펼침이 됩니다. `←` `→` `Space` `PageUp/Down`으로도 넘깁니다.

## 깃허브로 링크 배포하기

`main`에 push하면 GitHub Actions(`.github/workflows/pages.yml`)가 저장소를 그대로 GitHub Pages로 올립니다. 빌드 도구는 없습니다.

1. 제작기에서 **내보내기 → HTML 저장**으로 파일을 받습니다.
2. 받은 `.html` 파일을 저장소 `books/` 폴더에 넣습니다.
3. commit 후 push 합니다.

```powershell
copy "$env:USERPROFILE\Downloads\가정폭력_현장조치.html" books\
git add books
git commit -m "Add 가정폭력 현장조치 handbook"
git push
```

배포가 끝나면 링크는 다음과 같습니다.

```
https://dlrmsals1425-dotcom.github.io/police-ebook-maker/books/가정폭력_현장조치.html
```

책 목록 페이지(`books/index.html`)는 배포할 때 `books/` 안의 파일을 읽어 **자동으로 다시 만들어집니다**. 직접 고칠 필요가 없습니다. 로컬에서 미리 보려면 `node tests/build-shelf.js`를 실행합니다.

저장소가 공개라면 올린 책은 누구나 볼 수 있습니다. **외부유출금지 자료, 실제 사건 정보, 개인정보가 든 책은 올리지 마십시오.** 그런 책은 파일로 전달합니다.

GitHub 저장소 설정에서 **Settings → Pages → Source**를 `GitHub Actions`로 한 번 지정해 두어야 합니다.

## Markdown 확장

```markdown
# 제목

> point: 핵심 한두 문장
> tip: 현장 팁
> warning: 주의
> law: 관련 법령 요약
> example: 가상 사례
> summary: 한줄 요약
```

쪽 유형을 지정하려면:

```markdown
<!-- page: case -->
<!-- page: dodont -->
<!-- page: checklist -->
<!-- page: law -->
<!-- page: summary -->
```

표지 정보는 파일 맨 위 YAML로 넣을 수 있습니다.

```yaml
---
title: 가정폭력 신고 현장조치
subtitle: 초동조치 현장 핸드북
category: 초동조치
department: ○○경찰서 지역경찰과
date: 2026.03.01
version: 1.0
---
```

예제 파일:

- `samples/가정폭력_현장조치.md` — 짧은 변환 예
- `samples/전자책_활용가이드.md` — 우수사례·매뉴얼을 핸드북으로 쓰는 법

마스터 프롬프트는 앱의 **마스터 프롬프트** 버튼으로 받거나, `prompts/경찰교육전자책_마스터프롬프트.md`를 열면 됩니다.

## 저장

- 입력할 때마다 브라우저 `localStorage`에 자동 저장됩니다.
- **내보내기 → JSON 백업**으로 파일을 내려두면 다른 PC에서도 **파일 → JSON 불러오기**로 이어갈 수 있습니다.
- 문서 정보줄에서 저장 상태를 확인합니다. 저장 실패가 표시되면 JSON 백업을 내려받으세요. 입력 중에도 `Ctrl+S`로 저장할 수 있습니다.
- 외부 서버, 클라우드, API를 사용하지 않습니다.

좁은 화면에서 제작기를 열면 **쪽 목록 / 본문 편집 / 쪽 설정**으로 화면을 전환합니다. 본문 글자가 작으면 **너비 맞춤**을 누르고 세로로 스크롤해 편집합니다.

## PDF

**PDF 저장**을 누르면 브라우저 인쇄 창이 열립니다.

- 대상: `PDF로 저장`
- 용지: `152 × 225mm`가 보이면 그대로, 없으면 A4에 `용지에 맞춤`
- 여백: 없음
- 배경 그래픽: 켜기 (표지·장 표지 색이 나옵니다)

## 보안

- 기능 실행에 인터넷이 필요하지 않습니다.
- 폰트는 시스템에 설치된 한글 폰트(바탕·나눔명조·맑은 고딕 등)를 사용합니다.
- 이미지 블록은 파일에서 읽은 뒤 문서 안에 포함됩니다. 외부 주소 이미지는 넣지 않습니다.

```
index.html    제작기

```

## 변경 검증

```powershell
node tests/test-markdown.js
node tests/test-export.js
node tests/test-reader-runtime.js
node tests/test-app-save.js
node tests/test-editor-ime.js
node tests/test-learning-prompt.js
```

CSS나 마스터 프롬프트를 고쳤으면 묶음 파일을 다시 만듭니다.

```powershell
node tests/build-css.js      # css/*.css → js/ebook-css.js
node tests/build-prompt.js   # js/master-prompt.js → prompts/*.md
node tests/build-reader.js   # samples/전자책_활용가이드.md → book.html
node tests/build-shelf.js    # books/*.html → books/index.html
```

샘플 HTML만 다시 만들 때는 입출력 경로를 지정합니다.

```powershell
node tests/build-reader.js "samples/전자책_활용가이드.md" book.html
```

리더 동작과 저장 상태 테스트는 최소 DOM 모형으로 실행하며, 실제 브라우저의 조판·터치·인쇄 검사를 대체하지 않습니다.
