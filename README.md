# 경찰 교육 전자책 제작기

Markdown 교육자료를 올리면 경찰 내부교육용 전자책으로 바꾸고, 화면에서 고친 뒤 **휴대폰용 HTML** 또는 **PDF**로 배포할 수 있는 웹 앱입니다.

서버 없이 `index.html`만으로 동작합니다. 작성 내용은 브라우저 `localStorage`에만 남고 외부로 전송되지 않습니다.

배포는 책 앱·페이지 넘김이 아니라, 브라우저에서 스크롤하는 HTML 한 장입니다. 화면 너비에 맞춰 카드가 다시 흐릅니다.

## 바로 쓰기

- 제작기: https://dlrmsals1425-dotcom.github.io/police-ebook-maker/
- 샘플 HTML: https://dlrmsals1425-dotcom.github.io/police-ebook-maker/book.html
- 로컬: `index.html`을 더블클릭 (크롬·엣지 권장)

처음 열면 가상 샘플 「112 중요사건 현장조치 가이드」가 보입니다. 실제 사건·개인정보는 들어 있지 않습니다.

## 기본 사용 흐름

1. **마스터 프롬프트**를 받아 다른 AI 대화창에 붙여넣습니다.
2. 프롬프트 맨 아래 `[원본자료]`에 내 교육자료·사례·보고서를 붙입니다.
3. AI가 준 Markdown을 **Markdown 불러오기**로 엽니다.
4. 변환 후 **검토** 경고가 있으면 해당 페이지로 가서 긴 문장만 줄입니다.
5. 가운데 페이지를 클릭해 글을 고치고, 왼쪽에서 순서를 바꿉니다.
6. **미리보기** 뒤 배포 형식을 고릅니다.
   - **보내기 → HTML 저장**: 휴대폰 브라우저에서 스크롤해서 읽는 문서
   - **PDF 저장**: 인쇄·게시용 A4

마스터 프롬프트에는 전자책이 읽는 문법과 글자 수 제한이 들어 있습니다. 이 제한을 지키면 한 페이지가 잘리지 않습니다.

## Markdown 확장

```markdown
# 제목

> point: 핵심 한두 문장
> tip: 현장 팁
> warning: 주의
> law: 관련 법령 요약
> example: 가상 사례
> summary: 한줄 요약
```

페이지 유형을 지정하려면:

```markdown
<!-- page: case -->
<!-- page: dodont -->
<!-- page: checklist -->
<!-- page: law -->
<!-- page: summary -->
```

표지 정보는 파일 맨 위 YAML로 넣을 수 있습니다.

```yaml
---
title: 가정폭력 신고 현장조치
subtitle: 초동조치 교육자료
category: 내부 교육자료
department: ○○경찰서 지역경찰과
date: 2026.03.01
version: 1.0
---
```

예제 파일:

- `samples/가정폭력_현장조치.md` — 짧은 변환 예
- `samples/전자책_활용가이드.md` — 우수사례·매뉴얼을 핸드북으로 쓰는 법 + 이달의 교훈 사례 3건

마스터 프롬프트는 앱의 **마스터 프롬프트** 버튼으로 받거나, `prompts/경찰교육전자책_마스터프롬프트.md`를 열면 됩니다.

## 저장

- 입력할 때마다 브라우저 `localStorage`에 자동 저장됩니다.
- **보내기 → JSON 백업**으로 파일을 내려두면 다른 PC에서도 **백업 → JSON 불러오기**로 이어갈 수 있습니다.
- 외부 서버, 클라우드, API를 사용하지 않습니다.

## 휴대폰에서 보기

**보내기 → HTML 저장**으로 받은 파일을 카카오톡·USB로 보내고, 휴대폰 브라우저로 엽니다.

- 위에서 아래로 스크롤합니다. 페이지를 넘길 필요가 없습니다.
- 위쪽 **목차**를 누르면 해당 카드로 이동합니다.
- 글·표·DO/DON'T는 화면 너비에 맞춰 한 줄로 줄어듭니다.
- 같은 파일에서 **PDF**를 누르면 인쇄용 A4가 나옵니다.

이미 받아 둔 예전 HTML은 제작기에서 HTML을 다시 저장하면 됩니다.

## PDF

**PDF 저장**을 누르면 브라우저 인쇄 창이 열립니다.

- 대상: `PDF로 저장`
- 용지: A4
- 여백: 없음
- 배경 그래픽: 켜기 (표지·Chapter 색이 나옵니다)

## 보안

- 기능 실행에 인터넷이 필요하지 않습니다.
- 폰트는 시스템에 설치된 한글 폰트(맑은 고딕 등)를 사용합니다.
- 이미지 블록은 파일에서 읽은 뒤 문서 안에 포함됩니다. 외부 주소 이미지는 넣지 않습니다.
